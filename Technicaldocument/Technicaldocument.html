Introduction

JavaScript 是一门跨平台、面向对象的脚本语言。

JavaScript 是轻量级的，可嵌入网页中。

console.log("hi")
  • 网页交互
  • 服务端开发
What you should already know

本指南假设你有以下基础知识。

了解 HTML 和 CSS 基础。

let a = 1;
  • 基本网页结构
  • 基础编程逻辑
JavaScript and Java

JavaScript 和 Java 在很多方面不同。

JS 是弱类型脚本语言。

const name = "js";
  • 不需要编译
Hello world

下面是最简单的JS代码。

运行代码在控制台输出文字。

alert('Hello World')
Variables

变量用来存储数据。

可以使用 let、const、var 声明变量。

变量名称区分大小写。

var x = 100;
  • let 块级作用域
Data types

JavaScript 有七种基本数据类型和一种引用类型 Object。

可以使用 typeof 运算符查看值的类型。

typeof 42; // "number" typeof "hello"; // "string" typeof true; // "boolean" typeof undefined; // "undefined"
  • Number、String、Boolean
  • Undefined、Null
  • Symbol、BigInt
  • Object（引用类型）
Operators

运算符用于对值进行计算、比较和逻辑判断。

推荐使用严格相等 === 而不是 ==，避免隐式类型转换。

let sum = 5 + 3; // 8 5 === "5"; // false 5 == "5"; // true true && false; // false
  • 算术运算符：+ - * / %
  • 比较运算符：=== !== > <
  • 逻辑运算符：&& || !
if...else statement

if 语句在条件为真时执行一段代码。

可以用 else if 和 else 处理多个分支。

let score = 85; if (score >= 90) { console.log("优秀"); } else if (score >= 60) { console.log("及格"); } else { console.log("不及格"); }
  • 条件会被转换为布尔值
  • 0、""、null、undefined、NaN 都视为 false
Loops

循环用于重复执行相同的代码。

常见的有 for、while 和 for...of 循环。

for (let i = 0; i < 3; i++) { console.log(i); } let n = 0; while (n < 3) { n++; }
  • break 可以提前结束循环
  • continue 跳过本次循环
Functions

函数是一段可以重复调用的代码块。

函数可以接收参数，并通过 return 返回结果。

ES6 引入了更简洁的箭头函数写法。

function add(a, b) { return a + b; } const multiply = (a, b) => a * b; add(2, 3); // 5 multiply(2, 3); // 6
  • 函数声明会被提升
  • 箭头函数没有自己的 this
  • 参数可以设置默认值
Arrays

数组用于按顺序存储多个值，索引从 0 开始。

数组提供了很多实用的内置方法。

const fruits = ["apple", "banana"]; fruits.push("orange"); fruits.length; // 3 fruits.map(f => f.toUpperCase()); fruits.filter(f => f.length > 5);
  • push / pop：在末尾添加 / 删除
  • map：映射生成新数组
  • filter：筛选元素
  • forEach：遍历每个元素
Objects

对象是键值对的集合，用来描述复杂的数据。

可以通过点语法或方括号访问属性。

const user = { name: "Yuze", age: 20, greet() { return "Hi, " + this.name; } }; user.name; // "Yuze" user["age"]; // 20 user.greet(); // "Hi, Yuze"
  • Object.keys() 获取所有键
  • 解构赋值：const { name } = user;
DOM manipulation

DOM 是浏览器把 HTML 解析成的对象树。

JavaScript 可以通过 DOM 读取和修改页面内容。

const btn = document.querySelector("#btn"); btn.addEventListener("click", () => { document.body.style.background = "lightblue"; });
  • querySelector 选择元素
  • textContent / innerHTML 修改内容
  • addEventListener 绑定事件
